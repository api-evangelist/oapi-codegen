# oapi-codegen

> oapi-codegen is an Apache-2.0 licensed Go code generator that turns OpenAPI 3.0
> and 3.1 documents into Go types, HTTP clients, and server boilerplate for Chi,
> Echo (v4 and v5), Fiber (v2 and v3), Gin, Gorilla/Mux, Iris, and the standard
> library net/http router. It is configured with a YAML file validated by a
> published JSON Schema; command-line flags are maintained for backward
> compatibility only. It is a specification consumer with no hosted API of its own.
